# Mercenary Company Games

The official static website for **Mercenary Company**, a tactical extraction dungeon RPG in active development by Mercenary Company Games.

## Local preview

The site uses plain HTML and CSS. With Python installed, run this from the repository root:

    python -m http.server 8000

Then open http://localhost:8000.

## GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. The site files are at the repository root.

The root CNAME file records mercenarycompanygame.com. Configure the matching DNS records with the domain provider, then enter mercenarycompanygame.com under **Custom domain** in the Pages settings if GitHub has not already picked it up.
